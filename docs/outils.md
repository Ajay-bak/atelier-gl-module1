# Présentation des outils utilisés aucours de l'atélier

* Git/Github : Versionning/Stockage distant; C'est outils permettent de faire respectivement un suivis des modifications apportées au contenu d'un fichier et de la structure des dossier de l'espace de travail rattaché au dépôt distant appelé **Repositoire** qui conserve une version de l'espace de travail;

* VScode : Editeur de code 

* Python : Language de programmation interprété
